# 量具和渲染程序（参考用）

这里是 2026-11-22、11-23 拆红白大字风两条片子时用过的六个程序，照当时的原样放进来，给你拆别的风格时拿去改。

**它们不能直接跑。** 里面的文件名、帧号、坐标、字体都是按那两条片子写的，那两条片子和照片不在仓库里。用的时候让你的 AI 读懂它是怎么量的，再按你的片子改。

| 文件 | 干什么 |
| --- | --- |
| `量图轨迹.py` | 一张图滑进来时，量它每一帧的位置，看是不是同一条曲线 |
| `量字和标注.py` | 量大字和标注从第几帧开始出现、用几帧 |
| `量字幕.py` | 量字幕每一句的起止帧 |
| `验证预设曲线.py` | 把量出来的曲线套回各屏，看几处对不对得上 |
| `复刻渲染.py` | 「一屏一条数据」的渲染程序：照片、大字、标注、字幕按数据画出来 |
| `逐帧工具.py` | 上面几个共用的读帧小工具 |

要用到的东西：python3、numpy、Pillow、ffmpeg。
