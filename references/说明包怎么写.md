# 说明包怎么写（第 6 步）

什么时候读：做第 6 步之前。

说明包是给两种人用的：以后给这种风格做剪辑 Skill 和模板的 AI；照着这种风格做片子的剪辑师。两种人都没看过这次的对话，所以每条规矩都要自己说得清，每个数都指得到出处。

## 工作文件夹里最后有什么

```
<日期>_<账号名><内容类型>_剪辑拆解/
  风格说明包.md            这种风格的全部结论，入口
  第一条_逐屏拆解.md        每条片子一份
  第二条_逐屏拆解.md
  原片/                    第一条.mp4、第二条.mp4
  第一条/、第二条/          全片概况、总览图、动作条
  画面条/                  看细节时出的逐帧画面条
  片段/                    每种排法、每种动作配的原片小片段
  声音/                    音效对画面的表、找音效的工具的输出
  验/猜排法/               题目、答案、预测、得分
  验/重做/屏NN/            重做片、素材、色块素材、验收结果、对照条、三联片
  原始输出/                转写原文、别的切镜头工具的输出
```

## 风格说明包.md 的结构

照这个顺序写。没有内容的节写一句为什么没有，不留空，也不删。

1. **一句话结论。** 这种风格拆到了什么程度；最费人的是哪一步；拆解帮得上多少。
2. **这次拆的是什么。** 哪几条片子（文件、时长、屏数、哪条最新、作者按什么认的）、给谁用、在哪个软件做、手里有没有工程文件和原始素材。
3. **节奏。** 平均几秒一屏、一屏说多长的话、真人出镜占几成。
4. **画面排法清单。** 每种排法：长什么样、每条片子各用了几屏、典型的一屏、配的原片小片段。
5. **什么话配什么排法。** 标「我的判断」。后面接验法一的得分，写明这套规矩能不能让 AI 自动套。
6. **动作清单。** 每种动作：什么东西在动、用几帧、是不是固定曲线（是就给出每帧的数）、哪些屏用了、配的原片小片段。分三类写：固定曲线的、每屏不同的（开始帧、距离、帧数）、不是固定曲线的。
7. **标注清单。** 每种标注的样子（颜色、线宽、虚实）、出法、和口播的先后关系。
8. **大字和字幕。** 字体（最像的是哪款、差在哪、怎么变形）、颜色各用在什么词上、位置、出法。
9. **声音。** 多久一个音效、卡在什么上、配乐从哪到哪。没有人听过就写明。
10. **几条对着看。** 第 4 步那张表。
11. **三堆分工。** 见下面。
12. **验的结果。** 三样各自的数、对照图和三联片的链接；被重做验出来的错有哪几处、都改了没有；仍然来自原片的东西。
13. **没查的。** 一条一条列。

每种排法、每种动作配的原片小片段这样切，放 `片段/`：

```bash
ffmpeg -loglevel error -ss <开始秒> -t <时长秒> -i 原片/第一条.mp4 -c:v libx264 -crf 20 -an 片段/排法_黑底两张脸并排.mp4
```

## 三堆分工怎么分

每一样东西都要归进其中一堆，后面写依据。依据必须是量出来的数或验出来的结果，不是「我觉得」。

| 哪一堆 | 什么样的东西放这里 | 红白大字风里放了什么 |
| --- | --- | --- |
| AI 直接套 | 量得准、几条片子都一样、重做验过的 | 换屏在哪一帧、字幕时间、图摆在哪、图滑进来的曲线、常用的大字出法、照坐标画标注、排法做成模板 |
| 人来定 | 要专业判断或要挑素材的；验法一猜不中的 | 每句话配哪种排法（AI 先配、人改）、每屏用哪几张照片、点和线标在脸上哪里、真人出镜 |
| 交给剪映 | 只出现一两次的自带特效、认不出曲线的大字动画 | 放射状拖影、带透视的翻页、光斑扫过、两张脸变形过渡、甩动模糊 |

「人来定」这一堆不能缩水。它是用户判断这种风格值不值得做、剪辑师能省多少时间的依据。能省多少时间这次没测就写没测，不估一个倍数。

## 每条片子的逐屏拆解.md 的结构

1. 这条片子是什么（文件、宽高、帧率、时长、作者按什么认的、讲什么）。
2. 怎么拆的（看了哪些图、哪些是程序量的、哪些是眼睛看的、哪些没看）。
3. 整体情况（屏数、平均几秒一屏、真人占几成）。
4. 排法清单（这一条里出现的）。
5. 标注和大字。
6. 动效（进法各几屏、每种动作的帧数、哪些是量的哪些是看的）。
7. 逐屏拆解表。
8. 什么话配什么排法（我的判断）。
9. 素材是哪几类。
10. 校正后的口播全文。
11. 没做的。

## 交给用户时怎么说

1. 第一句是结论：这种风格拆到什么程度，最费人的是哪一步。
2. 三堆各有什么，每堆两三样，带数。
3. 验的结果：猜排法几屏中几屏（底线几屏）；重做了几屏、几屏过线；色块重跑后还有什么来自原片。
4. 文件链接（说明包、每条的逐屏拆解、三联片）。链接写完整路径。
5. 三行自查：查了什么、查出什么、改了什么。再列「没查」。

发出去之前，把说明包里的每个数对着原始数据核一遍，每个链接点一遍。红白大字风那次，每次交付前自查都查出了数错的地方。
